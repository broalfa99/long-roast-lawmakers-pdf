## The entry

> The senator who wants to license every AI model in America still emails his staff a photo of his screen because he cannot find the button that turns a document into a PDF.

One sentence, 171 characters — a roast of lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF. No real person is named; the joke is about the situation.

## How it works

`main.py` writes that single sentence to `/output/entry.txt`. It refuses to write anything outside the competition gate (1–320 characters, one line), so an invalid entry can never be submitted by accident.

```sh
python3 main.py
cat /output/entry.txt
```
